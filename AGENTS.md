# Project workflow

The repository owner has authorized pushing completed changes directly to `main` after testing, including future changes in this project. Include the relevant source files, tests, documentation, assets, and browser test screenshots. Do not force-push or discard unrelated remote changes. Follow any newer owner instructions that change this preference.

Run the Node rules/controller tests documented in README.md. For changes to layout, interactions, or animation, also run the relevant browser suites. Keep the game fitted to its viewport without page scrolling, including fullscreen and embedded mode.
